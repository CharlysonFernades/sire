## Critério de documentação

A documentação separa claramente:

- **Implementado:** comportamento presente na versão atual analisada;
- **Planejado:** funcionalidade prevista, mas ainda não considerada concluída;
- **Dependente de configuração externa:** recursos que também dependem do Firebase Console, das Firestore Security Rules ou de serviços externos.

Essa separação evita que itens do roadmap sejam apresentados como funcionalidades já disponíveis.
